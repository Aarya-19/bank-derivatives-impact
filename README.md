# bank-derivatives-impact
# Impact of Derivatives Usage on Bank Stability, Valuation and Risk

An empirical research project investigating how off-balance-sheet derivatives portfolios affect bank-specific risk profiles, valuation and stability metrics using Bloomberg data, unsupervised clustering, and panel regression techniques.

## Methodology
- **Clustering:** Applied K-means clustering to segment institutions based on asset size, derivatives notional volume, and leverage.
- **Risk Modeling:** Evaluated the relationship between derivatives exposure and unsystematic risk metrics.
- **Econometrics:** Utilized panel data regression models to control for macroeconomic factors and unobserved heterogeneity.

## Repository Layout
- `scripts/`: Data cleaning pipelines and regression scripts.
- `outputs/`: Generated charts, regression output tables, and cluster summaries.
